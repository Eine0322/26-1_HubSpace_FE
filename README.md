## 📍 프로젝트 개요

비로그인 구글 폼으로 신청을 받으니 중복 신청과 불필요한 문의가 들어온다. 내가 맞게 신청했는지 검색해 볼 수 있는 조회 서비스 및 이벤트 관리 서비스를 만들자!

💡특정 이벤트에 얽매이지 않고 언제든 조회할 수 있는 전용 조회 서비스

이 서비스는 **이벤트(폼·파일)를 생성하고, 응답 데이터를 효율적으로 수집·관리·조회하기 위한 관리자 중심 웹 서비스**입니다.

<br/>

## 📍 주요 기능

- 구글 소셜 로그인
- 이벤트 구글 폼 생성
- 기존 csv 파일 등록 후 조회가능한 이벤트 생성
- 이벤트 별 응답 데이터 조회 기능
- 진행 중인 이벤트 통합 관리 기능
